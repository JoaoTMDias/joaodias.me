# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or
social-media post.

Report them privately through [GitHub Private Vulnerability Reporting](https://github.com/JoaoTMDias/joaodias.me/security/advisories/new).
Include the affected URL or component, reproduction steps, potential impact, and any suggested
mitigation. Avoid accessing, changing, or retaining data that does not belong to you.

The maintainer will acknowledge the report when practical, investigate it, and coordinate any
public disclosure after a fix is available. Because this is a personal project, no response or
resolution timeframe is guaranteed.

## Supported version

Only the code currently deployed at [joaodias.me](https://joaodias.me) and the latest commit on the
`main` branch receive security fixes.
